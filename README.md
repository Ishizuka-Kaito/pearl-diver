# 真珠潜り ｜ Pearl Diver

海図を10秒間下見し、30秒の潜水で真珠を船に持ち帰る探索アクションです。もう一つ先の貝を拾うか、いま持っている真珠を確実に届けるか。残り時間・空気・帰り道を見ながら決めます。

**[プレイ動画を見る・ブラウザで遊ぶ](https://ishizuka-kaito.github.io/pearl-diver/)**

[![真珠潜りのタイトルイラスト](cover.png)](https://ishizuka-kaito.github.io/pearl-diver/)

## 遊び方

- 下見中に左右キーで船の潜水口を選び、潜水開始後に下キーで入水します。9種類の海域で通路や貝の位置が変化します。
- 方向キー・WASD・海中タップで泳ぎます。桃色の貝は100点、金色は300点。制限時間内に船へ運んだ分が得点になります。
- Shift長押しで泳ぐ速さが1.65倍、泳いでいる間の空気消費が2.4倍になります。船と泡の湧く岩で補給できます。
- Bで海中に1本だけロープを設置できます。線の近くでBを押し、↑で船へ、↓で設置点へ移動します。ロープ上では空気を使わず、移動中に方向キーを押すと途中で降りられます。

画面下のボタンでも操作できます。Escapeで一時停止・再開できます。

## 実装とローカル起動

得点・運搬、作戦時間と潜水時間、ダッシュ時の空気消費、補給・救助の判定は [game.py](game.py) に実装しています。ブラウザでは同梱のBrythonがPythonを実行します。海域生成と当たり判定、ロープに沿った移動、ドット絵の描画は [scene.js](scene.js)、画面と入力は [ui.js](ui.js) が担当します。

Python 3 がある環境では、このディレクトリで次のコマンドを実行し、ブラウザで [ローカル版](http://127.0.0.1:8000/) を開いてください。

```sh
python -m http.server 8000 --bind 127.0.0.1
```
